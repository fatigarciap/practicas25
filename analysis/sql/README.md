# SQL Domain Structure

Esta carpeta contiene scripts historicos en la raiz y la estructura canonica propuesta por dominios.

Los scripts existentes en `analysis/sql/*.sql` no se han movido ni modificado. Las subcarpetas nuevas documentan la organizacion final recomendada:

- `cohort/`
- `antibiotics/`
- `windows/`
- `daily_features/`
- `outcome/`
- `final_table/`
- `qc/`

Los archivos con sufijo `_reconstructed.sql` son placeholders metodologicos creados desde el audit, no scripts listos para ejecutar.
